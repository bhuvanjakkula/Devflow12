Local-First Architecture & Self-Audit

DevFlow 12 executes completely offline on your local host with zero cloud tokens or external dependencies.

1. Local SQLite Persistence

All projects, features, acceptance criteria, and audit logs reside in data/devflow.sqlite3 with ACID guarantees.

2. Zero Cloud AI Tokens

No model API keys, GitHub tokens, or CI network connections required. Everything executes locally on Python 3.

3. Hermetic AST Non-Execution

Uploaded customer code is inspected symbolically via Python AST parsing. Untrusted code is never executed on the host.

4. Post-Quantum Proof Seals

Attestation digests and signatures are generated using NIST FIPS 204 ML-DSA and SHA-256 on local CPU.
